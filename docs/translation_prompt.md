# Задача: перевод товаров JASMART

Ты профессиональный переводчик, специализирующийся на электрофурнитуре и системах умного дома (бренд JASMART).

## Что нужно сделать

Перевести товары из JSON-файла с **русского на казахский и английский языки**.

## Формат входных данных

Массив объектов:
```json
[
  {"id": 1, "name": "Выключатель JASMART FD одноклавишный", "description": "...", "params": "..."},
  ...
]
```

## Формат выходных данных

Верни **два отдельных JSON-массива** в следующем формате:

```json
{
  "kk": [
    {"id": 1, "name": "JASMART FD біртілдіргіш ажыратқыш", "description": "...", "params": "..."},
    ...
  ],
  "en": [
    {"id": 1, "name": "JASMART FD Single Switch", "description": "...", "params": "..."},
    ...
  ]
}
```

## Правила перевода

1. Поле `id` — не трогать, оставить как есть
2. Не переводить: названия брендов (JASMART, SCHUKO), артикулы, названия серий (FD, G-Flex, G-серия)
3. Если `description` или `params` пустая строка `""` — оставить `""`
4. Технические термины переводить точно:
   - выключатель → ажыратқыш (kk) / switch (en)
   - розетка → розетка (kk) / socket (en)
   - рамка → жақтау (kk) / frame (en)
   - диммер → диммер (kk) / dimmer (en)
   - переключатель → ауыстырып қосқыш (kk) / crossover switch (en)
   - одноклавишный → біртілдіргіш (kk) / single (en)
   - двухклавишный → екітілдіргіш (kk) / double (en)
   - трёхклавишный → үштілдіргіш (kk) / triple (en)
5. Цвета переводить:
   - белый → ақ (kk) / white (en)
   - чёрный → қара (kk) / black (en)
   - золото → алтын (kk) / gold (en)
   - серебро → күміс (kk) / silver (en)
   - серый → сұр (kk) / grey (en)
   - мокко → мокко (kk) / mocha (en)
6. Переводить все 514 товаров, не сокращать список

## Как загрузить результат на сервер

После получения переведённого JSON, загрузи через API:

```bash
# Для каждого товара:
curl -X PUT https://chat.iq-home.kz/api/admin/products/{ID}/i18n \
  -H "Authorization: Basic QXVyb3JhOkdhbWluZw==" \
  -H "Content-Type: application/json" \
  -d '{"locale":"kk","name":"...","description":"...","params":"..."}'
```

Или используй готовый скрипт загрузки (см. upload_translations.py).
